# Universal

Librería y utilidades compartidas en Go:
- **CBPR**: Concurrent Batch Processing & Reporting.
- **GeoRoute**: Detección de país, enrutamiento geográfico y administración de proxies.
- **HTTPClient**: Cliente HTTP avanzado con soporte para emulación TLS (tls-client, uTLS, fhttp), sesiones persistentes, pool de proxies, perfiles y workers.
- **Progress**: Pipeline concurrente con colas de trabajo, monitoreo y reintentos automáticos.
- **Utils**: Funciones generales de codificación, dominios, variables y países.
